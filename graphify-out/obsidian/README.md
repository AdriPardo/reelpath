# Reelpath — vault Obsidian (graphify)

Abre esta carpeta como vault en Obsidian:

1. Obsidian → **Open folder as vault**
2. Elige `graphify-out/obsidian`
3. Usa **Graph view** o abre `graph.canvas`

Regenerar tras cambios de código:

```bash
graphify update .
./scripts/graphify-export-obsidian.sh
```

No edites a mano las notas de nodos: se sobrescriben.
Más detalle: `docs/GRAPHIFY.md`.
