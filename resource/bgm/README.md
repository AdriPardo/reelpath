# Background music (BGM)

Put royalty-free audio files here (`.mp3`, `.m4a`, `.wav`, `.ogg`, …).

Reelpath mixes a random track (or `ChannelConfig.bgmFile`) under the voice when
`ChannelConfig.bgmEnabled=true`.

User uploads can also live under `storage/bgm/` (runtime, not committed).

Do **not** copy tracks from MoneyPrinterTurbo `resource/songs/` — bring your own
licensed / royalty-free music.
